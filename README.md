# Jídelníček

Jednoduchá webová aplikace na jídelníček (zatím obsahuje BMI kalkulačku).

## Soubory

- `index.html` – struktura stránky (formulář, výsledek)
- `style.css` – vzhled (barvy, rozložení, mobilní design)
- `app.js` – logika (výpočet BMI, kategorie, ukládání do prohlížeče)

## Spuštění

Stačí otevřít `index.html` v prohlížeči. Pro zveřejnění zapněte
GitHub Pages: **Settings → Pages → Branch: main / (root)**.
